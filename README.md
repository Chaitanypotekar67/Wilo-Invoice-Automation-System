# Wilo Invoice Automation System

## Project Overview
The Wilo Invoice Automation System is a solution designed to simplify invoice processing through mobile invoice capture, OCR-based data extraction, and a web-based dashboard.

## Key Features
- Mobile-based invoice capture.
- QR-code-based connection between mobile and web interfaces.
- OCR-based invoice data extraction.
- Web dashboard for viewing and managing invoice records.
- Dark mode and account settings.

## OCR Technology Comparison

| OCR Technology | Document Accuracy | Processing Time |
|---|---:|---:|
| Tesseract OCR | 90% | 1 minute |
| Azure OCR | 95% | 1 minute |
| PaddleOCR | 87% | 1–2 minutes |
